# TetraBooks corpus

## Public-domain classics

These plain-text files were downloaded from Project Gutenberg for the local demo:

- `raw/le_morte_darthur_volume_1.txt` — [ebook 1251](https://www.gutenberg.org/ebooks/1251)
- `raw/le_morte_darthur_volume_2.txt` — [ebook 1252](https://www.gutenberg.org/ebooks/1252)
- `raw/the_count_of_monte_cristo.txt` — [ebook 1184](https://www.gutenberg.org/ebooks/1184)
- `raw/don_quijote_de_la_mancha.txt` — [ebook 2000](https://www.gutenberg.org/ebooks/2000)
- `raw/el_conde_de_montecristo_es.txt` — [edición española del Gobierno argentino](https://www.argentina.gob.ar/sites/default/files/el_conde_de_montecristo_dumas.pdf)

The Spanish demo knowledge base is `TetraBooks Classics ES`. It contains the Spanish
Don Quijote, the Spanish Montecristo edition, and the two original reference documents
below. The older Spanish translations listed by [Wikisource](https://es.wikisource.org/wiki/El_conde_de_Montecristo)
are useful alternatives when a facsimile or OCR workflow is desired.

Project Gutenberg identifies these works as public domain in the United States. Check
the laws and Project Gutenberg terms applicable to the intended jurisdiction before
redistributing the corpus.

## Original Spanish reference documents

- `raw/rey_arturo_guia_es.md` — original synthesis of recurring Arthurian themes; not a modern translation.
- `raw/batman_alfred_ficha_es.md` — original short reference; no comic dialogue or scraped DC text.

## Batman and Alfred

Batman and Alfred are DC characters. Do not add full comics, novels, or scraped
character text without an appropriate license. For the demo, use the [official Batman
profile](https://www.dc.com/characters/batman) and [official Alfred profile](https://www.dc.com/characters/alfred-pennyworth)
as reference links, or add user-provided/licensed material.
